# UX UI аудит

## Критические находки

- Строки таблиц и карточки на `data-href` работают мышью, но не клавиатурой.
- Клиентская сортировка отдельных `tr` разрывает связанные строки задачи/лога и события/детали.
- Основная форма обращения не связывает labels и ошибки с полями через `for`, `aria-invalid` и `aria-describedby`.
- В мессенджере открытие диалога отмечает прочитанными сообщения всех тем, включая неоткрытые.
- Компоненты используют отсутствующие CSS variables `--radius-lg`, `--surface`, `--secondary`, `--shadow-md`; особенно страдает тёмная тема.
- Пагинация может дублировать query-параметр `page` и оставить пользователя на старой странице.
- Mobile navigation и master/detail мессенджера требуют отдельной переработки.

## Первая UX вертикаль

Сценарий `реестр → карточка → редактирование → сохранение`: реальные ссылки и доступная сортировка, единый field renderer с ARIA-ошибками, исправленная пагинация, системные CSS tokens, reduced motion, keyboard-only и 1024/1366/1920 browser checks.
