# Визуальная проверка

Скрипт `scripts/visual_qa.mjs` запускает отдельный headless Chrome, входит под локальной
QA-учётной записью и сохраняет снимки и JSON-отчёт в `.artifacts/visual-qa/`.

```bash
QA_USERNAME='<local-user>' QA_PASSWORD='<local-password>' node scripts/visual_qa.mjs
```

При необходимости задаются `QA_BASE_URL`, `QA_OUTPUT_DIR` и `CHROME_PATH`. Учётная запись
должна иметь доступ ко всем проверяемым административным разделам. Пароль не записывается
ни в отчёт, ни в имена файлов.

Дополнительные состояния можно включить JSON-массивом пар `имя — путь`, например
`QA_EXTRA_ROUTES='[["journal-overdue","/journal/12/"]]'`.

Для проверки ограниченной роли перечислите ожидаемые 403 через имена маршрутов:

```bash
QA_USERNAME='<operator>' QA_PASSWORD='<password>' \
QA_EXPECT_FORBIDDEN='events,tasks,users' \
QA_OUTPUT_DIR='.artifacts/visual-qa-op' node scripts/visual_qa.mjs
```

Прогон завершается с ошибкой, если маршрут вернул страницу входа, неожиданную 403,
не вернул ожидаемую 403, зарегистрировал JavaScript/CSP-ошибку в браузере или ширина
документа оказалась больше viewport. Также проверяется, что заявленные в имени сценария
тема, масштаб шрифта и контраст фактически применены к DOM, а CSS transitions завершены
до измерений и снимка. Горизонтальная
прокрутка внутри специально предназначенного для неё контейнера таблицы допустима. PNG
остаются локальными артефактами и не коммитятся.
